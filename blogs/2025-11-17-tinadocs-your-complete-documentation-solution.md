Over the past few months we've been building a new documentation starter template designed to make it easier for teams to create, edit and maintain docs using TinaCMS. This project is now publicly available as TinaDocs, a starter package designed to specifically target a fully-structured documentation setup built on Next.js and TinaCMS. To try it out without installing it - try the online demo sandbox!
