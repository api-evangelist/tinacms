We're excited to introduce some new Editorial Workflow features for teams on TinaCloud's Business and Enterprise plans! Enabling Editorial Workflow features on a project allows editors to work on branches and make PRs without logging into GitHub. We understand that Git concepts are new to many content editors, so the TinaCMS Editorial Workflow offers an approachable UX that makes Git easy.
