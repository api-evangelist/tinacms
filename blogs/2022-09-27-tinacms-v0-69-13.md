Announcing TinaCMS 0.69.12 Today, we are releasing a new version of Tinacms. This version adds several improvements including; A new default values behavior Filename customization New default values behavior To start we are deprecating the use of defaultValue this value would misbehave and make it hard or impossible in some cases to nullify a value. Now defaultItem can be provided at the collection level.
