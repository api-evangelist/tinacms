TinaCMS now has a public roadmap where you can follow along with high-level features on our radar. !Public Roadmap The roadmap is reserved for items in which we have a high degree of confidence that they'll fall into a given timeframe. Each roadmap item will link to a GitHub discussion, where you can comment on features, or subscribe for updates.\ \ If you'd like to see something make its way into the roadmap, start by creating a feature request in our GitHub Discussions.
